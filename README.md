# Text Analyzer

A C++ text analyzer that processes user input and provides basic text statistics.

## Version 1.0 Features

* Character Count
* Word Count
* Vowel Count
* Consonant Count
* Automatic Lowercase Conversion

## Technologies Used

* C++
* STL

## Future Improvements

* Digit Count
* Special Character Count
* Character Frequency Analysis (Hashing)
* Most Frequent Character
* Word Frequency Analysis
